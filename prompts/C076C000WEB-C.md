## Критерии готовности
1. Модель grant/deny на module capability, read/write/admin, объект, поле и caller; deny имеет приоритет над allow, модуль не получает права на чужой namespace.
2. Согласованный интерфейс `allowed/require`, запрет неизвестной capability и невалидного caller, 401/403/409, enforcement не только скрытие пунктов меню.
3. Негативные тесты прямого API, data export, row/field ACL, admin without declared capability, cross-user, cross-module, попытка имитации провайдера.
4. SQLite/disposable adapter и handoff с exact integration points в 034/records alpha; SQL Manager proposals без DDL в runtime.
