1. Доверенная регистрация service_id/version/capability/schema/deadline, no foreign namespace or duplicates; схематическая/JSON валидация запросов и ответов.
2. Fail-closed delegated ACL: caller and provider both enabled, declared permissions, allowlist caller/provider/service/version, explicit trusted context; отсутствие CRM028 adapter = FORBIDDEN/UNAVAILABLE.
3. Ошибки 403/404/409/413/422/429/502/503/504, ограничение времени/данных/рекурсии, смена generation при обновлении, безопасное логирование.
4. Два рабочие независимые модуля-fixture и один запрещённый пример, отрицательные тесты impersonation/stale generation, handoff 034; настоящие 030 IPC E2E NOT RUN до интеграции.
