# C052D000TST

Ты выполняешь один самостоятельный тестовый контракт BROWN SWARM: C052D000TST. Не выполняй другие контракты.

## Задание
Составь таблицу умножения числа 17 на целые числа от 1 до 20 включительно.

## Критерии
Ровно 20 строк вида 17 × n = результат, в порядке возрастания n; все произведения верны.

## Формат выдачи
Выдай фактический результат непосредственно в чате. Не создавай файлы, не работай с GitHub и Google Drive. Не добавляй пояснения, отчёт о подсчёте или заголовки к результату. Для заданий на число слов считай слова по пробельному разделению (слово с внутренним дефисом считается одним); для рассказов используй однозначные границы предложений, без сокращений с точками.
