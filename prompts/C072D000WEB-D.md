### Конкретный публичный контракт адаптера
Используй vanilla JS (ES module) + CSS без сторонних библиотек и без удалённого импорта. Панели задаются JSON `{version:1,moduleId:string,panels:[{id:string,title:string,kind:"panel"|"tab",x:number,y:number,w:number,h:number,visible:boolean}],activeId?:string}`. IDs: `[a-z][a-z0-9_-]{0,39}`, число панелей максимум 48, координаты и размеры finite positive numbers within 0..10000, bounding rectangle clipped to root; `onChange(nextLayout)` вызывается после согласованного изменения; `onAction(action)` только для whitelisted action types; storage callback `load(key)` и `save(key,layout)` may be async, key formed from trusted moduleId+caller userContext not localStorage. Styles scoped `.seka-workspace-alpha`; DOM generated via `createElement/textContent`, never `innerHTML`; avoid untrusted HTML, JS and URLs. Schema validator produces precise errors; provide explicit cleanup/dispose and tests.
