Продолжить CRM026 и подготовить функциональный локальный модульный lifecycle: проверка пакета, staging, включение, update, rollback с сохранением независимости соседнего модуля. Не производить реальную установку на сервер и не менять core.

Работай как ChatGPT Worker с GitHub-доступом к указанному закрытому проекту; если доступ отсутствует, немедленно BLOCKED с полным handoff. На публичный репозиторий ContractsPolivas патчи/исходники не публикуй.

## Критерии готовности
1. Trusted package/checksum/manifest/version/channel validation, reject traversal/symlinks, service registration generation handoff.
2. Независимая install→update→rollback модель на temp dirs, атомарное переключение версии или честный PENDING для интеграции host, recovery после сбоя.
3. Тест независимости двух модулей (обновление A не ломает B), rejection malformed package, rollback fail/recovery, version mismatch.
4. Точный CRM034 integration_handoff для route switch/permissions; реальные systemd и PG18 tests NOT RUN до разрешённого deployment.
