# ContractsPolivas — публичная очередь BROWN SWARM

Актуальные документы: [INDEX.md](INDEX.md) — активная очередь; [CUTTER.md](CUTTER.md) — постановщик; [NUMBERING.md](NUMBERING.md) — формат ID и резервирование номеров.

Dispatcher 0.9.10 / Firefox Worker 0.9.1 (V15): локальные тесты PASS, живая приёмка NOT RUN.

## Принципы

Dispatcher — курьер, не контролёр. Читает публичный INDEX, выдаёт полные задания, получает ответы и пакетно доставляет реальные результаты GPT. Не пишет в GitHub, не оценивает качество, не проверяет SHA публикации, не требует PROCESSED или отдельного Publisher. D-результат — оригинальный текст, G-результат — ссылка на реально созданный файл. GPT подключён к трём дискам по подтверждению владельца. GPT сохраняет текст/проверяет наличие файла и убирает соответствующую строку INDEX; если не удалось, оставляет её. Независимый Validator проверяет качество.

Обычные совместимые задания: собственные готовые задачи в приоритете, затем D→G→C / G→C. Сохраняются ID, исходный тип результата и ограничения доступа. BLOCKED эскалируется новой попыткой к более старшему совместимому исполнителю. Специальные роли закреплены. GPT сначала доставляет результаты. Уже отправленную задачу не прерывает.

Зависимости снимаются только после успешного чтения актуального INDEX без всех номеров блокеров. Ошибка сети не означает пустую очередь. Исчезнувшие ID не переотправляются. История сохраняется. F приоритетен только среди готовых.

Номера и блокеры переменной длины, минимум три цифры. Порядок и пределы — в NUMBERING.md. Публичные карточки не расширяют полномочия и не должны содержать секреты.

Использовать [CUTTER.md](CUTTER.md) перед каждой новой нарезкой. Удаление материалов только по указанию владельца, без переписывания истории Git.
