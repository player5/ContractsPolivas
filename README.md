# ContractsPolivas — публичная очередь BROWN SWARM

**Актуальная очередь:** [INDEX.md](INDEX.md). В пилоте C001 DeepSeek уже вернул исходный ответ, а V002 — обычное независимое задание ChatGPT, **готовое к выдаче после получения ответа C001**, без отдельного Publisher.

## УТВЕРЖДЁННОЕ ПРАВИЛО ВЛАДЕЛЬЦА (2026-11-23)

**Dispatcher — курьер, а не контролёр.** Читает публичный INDEX, выдаёт полные задания указанным исполнителям, получает ответы и прикладывает реальные данные к следующему **обычному GPT-заданию**. **Не проверяет**, правильно ли написан текст, сколько слов, соответствует ли ответ ТЗ, совпадает ли SHA опубликованного файла. Содержательная проверка — исключительно отдельный контракт Validator, если он назначен.

Для DeepSeek передаёт оригинальный захваченный текст как данные. Для Gemini — только фактические ссылки на уже созданные файлы его Google Drive, без перепаковки/копирования. Подключение GPT к трём дискам подтверждено владельцем. GPT в начале обычной работы фиксирует результаты, при наличии/создании файла убирает только строку соответствующего ID из активного `INDEX.md`. **Не нужен статус PROCESSED в карточке** и не нужен отдельный GPT Publisher. Нет файла/прав — GPT не убирает строку и продолжает свою задачу.

**Dispatcher перечитывает один источник истины — активный INDEX.** Если ранее выданный ID исчез оттуда, он перестаёт его отправлять, отслеживать и доказывать. Локальная история не удаляется; минимальная отметка об исчезновении нужна только для восстановления порядка зависимостей после перезапуска, не для оценки качества. При ошибке сети/недоступном INDEX отсутствие не предполагается.

## Назначение исполнителей и зависимости

[Утверждённая нумерация](NUMBERING.md): `<ROLE><NNN><MODEL><DEP><SERIES>[F]`; `D` DeepSeek, `G` Gemini, `C` ChatGPT. Модель в готовом ID жёстко закреплена — не подменять даже если занята. Только для **неназначенных** совместимых задач выбор свободных исполнителей по порядку **D < G < C** до выпуска окончательной карточки. Конечная `F` — срочный фикс Validator без обхода зависимостей.

Зависимое обычное GPT-задание можно отправлять **после получения ответа предшественника**: оно получит краткую служебную вставку с исходным текстом/путём и сможет выполнить учёт перед основной работой. Это не утверждение о качестве результата.

Текущие контракты: [C001D000TST](contracts/C001D000TST.md), [V002C001TST](contracts/V002C001TST.md). История и сохранённые результаты остаются; меняется только активный индекс по решению авторизованного GPT/Producer.

**Текущий статус реализации:** Go- и Firefox-тесты облегчённого кандидата PASS; живой проход в браузере после этой правки **NOT VERIFIED**. Ранее установленный UNIVERSAL содержит старый механизм публикации; его состояние нельзя путать с поведением нового кандидата.
