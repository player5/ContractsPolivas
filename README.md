# ContractsPolivas — публичная очередь BROWN SWARM

**Актуальные контракты:** [INDEX.md](INDEX.md). В тестовой серии ровно два ID: [C001D000TST](contracts/C001D000TST.md) (DeepSeek, исходный ответ уже сохранён Dispatcher) и [V002C001TST](contracts/V002C001TST.md) (ChatGPT, независимая проверка после учёта первого).

**Ключевое решение владельца от 2026-11-23:** Dispatcher только читает публичные карточки, выдаёт задания согласно закреплённой модели, забирает факты выполнения и не оценивает качество. Отдельного GPT Publisher и SHA-проверки при закрытии очереди **не требуется**.

1. Если DeepSeek вернул `DONE`, оригинальный текст сохраняется локально и добавляется к **следующему обычному GPT-заданию** как служебная запись, не новая Publisher-задача. GPT записывает полученное в разрешённый результатный файл и отмечает исходную карточку `PROCESSED`.
2. Если Gemini сообщил `DONE` и **реальную ссылку** на файл своего Drive, GPT при следующем своём задании проверяет наличие файла на подключённом Drive и отмечает контракт `PROCESSED`. Повторно копировать файлы Gemini нельзя без явной нужды.
3. Для обычного ChatGPT-контракта служебная проверка уже завершённых ID помещается **перед основной задачей**, а после выполнения собственной задачи GPT может в той же работе учесть и свой результат. **Не отвлекать GPT отдельным пустым запросом только ради учёта.**
4. Если файл не виден, запись остаётся в очереди; GPT выполняет свою основную задачу. `PROCESSED` означает только учёт результата, не содержательный PASS.
5. Dispatcher читает `PROCESSED` в карточке и отсутствие её строки в активном `INDEX.md`, чтобы открыть заявленные зависимости. Он **не пишет GitHub, не хеширует содержимое при публикации и не придумывает статусы/ссылки**.

**Маршрутизация:** [утверждённые правила нумерации](NUMBERING.md): `<ROLE><NNN><MODEL><DEP><SERIES>[F]`; `D` DeepSeek, `G` Gemini, `C` ChatGPT. Закреплённый исполнитель не заменяется ни при какой занятости. Для **пока не назначенных** подходящих заданий порядок свободных исполнителей: **D < G < C**. Конечная `F` — срочный фикс от независимого Validator с соблюдением зависимостей.

**Права и сохранность:** убрать выполненное из активного `INDEX.md` — не удалить карточку/историю/файл. GitHub изменяет только авторизованный GPT/Producer. Другие проекты и реестры не затрагиваются.
