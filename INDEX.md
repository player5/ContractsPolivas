## Что делает Dispatcher

1. Читает эту таблицу и полные карточки. **Не пишет в GitHub, не назначает исполнителя вместо указанного в ID и не меняет статус самостоятельно.**
2. Выдаёт обычные задания только назначенной модели. Для **неназначенных** задач до закрепления ID предпочтение свободных подходящих исполнителей: **D → G → C**. Для закреплённых D/G/C при занятости ждёт назначенную модель, без подмен.
3. Когда ответ исполнителя получен и захвачен, фиксирует только факт получения. **Не оценивает** текст, количество слов, `DONE` как качество, ссылку на Drive или содержимое файла.
4. Следующее **обычное GPT-задание** получает маленький служебный блок: фактически полученные результаты DeepSeek (текст) и указанные Gemini ссылки на Drive. GPT записывает DeepSeek-ответ, если может; для Gemini проверяет наличие указанного файла. Потом просто убирает соответствующую **строку ID** из активного `INDEX.md`. Не удаляет карточки, историю или результаты. Никакого отдельного Publisher.
5. Зависимый контракт допускается к выдаче **после получения ответа предшественника**, без ожидания SHA или специального состояния карточки. Для C001 → V002 это означает, что V002 как обычная GPT-задача получает прежний текст C001 в служебной вставке, а затем выполняет независимую проверку.
6. После очередного чтения GitHub Dispatcher **забывает исчезнувшие из активной таблицы ID**, не переотправляет их и не ищет дополнительные свидетельства. Локальные исторические данные не удаляются.
7. Контракт `...F` (фикс от независимого Validator) имеет приоритет над обычными готовыми задачами, но не обходит реальные зависимости.

**Обязательное различие:** доставлено / убрано из очереди ≠ содержательно проверено / принято владельцем. За качество отвечает исключительно отдельное задание Validator. **Никаких проверок результата в Dispatcher.**

**C001 уже ответил** в установленном ранее UNIVERSAL, локальный захваченный ответ сохраняется при обновлении программного ZIP. Повторное выполнение не требуется. V002 предназначен исключительно для ChatGPT; до фактического браузерного теста новой облегчённой схемы его исполнение **NOT VERIFIED**.
