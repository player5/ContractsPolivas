# Обязательный транспортный шаблон карточки

**TEMPLATE / НЕ ЗАДАНИЕ.** В реальный contracts/<ID>.md копировать только содержимое блока, заменив placeholders фактическими значениями.

```md
- `contract_id`: `<ID>`
- `prompt`: [Задание](../prompts/<ID>-<PROVIDER>.md)
```

PROVIDER — DeepSeek, Gemini или ChatGPT. Точные примеры всех моделей и Validator, строк INDEX и обязательная проверка: [CUTTER.md](../CUTTER.md). Дополнительные поля допускаются только по актуальному регламенту. Полное ТЗ, base commit, границы, права и критерии — в промпте. Публичная карточка не расширяет полномочия, не даёт разрешения на merge/деплой; секреты и закрытые данные не публиковать. Worker не выдаёт независимый PASS.
